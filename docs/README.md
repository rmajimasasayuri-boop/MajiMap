# Maji Map · 公開マップ

外来受付と病棟入口への院内ナビゲーションです。GitHub Pagesでは、このdocsフォルダを公開します。

- 地図の1つの「2D／3D」ボタンで切り替え。3Dは経路全体を常に表示し、各階の間隔を自動調整して重なりを防ぎます。動く矢印で進む向きを確認し、病棟名・施設名のクリックで直接設定できます（出発地は青枠、目的地は赤枠）。
- 3Dは1本指で移動、2本指で拡大縮小・回転。地図は指で拡大縮小できます。ナビの青い点は手順に沿って動く案内位置で、自動測位ではありません。案内欄を左右スワイプして手順を切り替えます。
- 常設検索欄へ直接入力し、左側（スマホは下側）の写真付き施設カードからナビを開始できます。ホバーは青／赤の枠、クリックで下段の写真付き施設カードを表示します。文字入力時は全候補を検索。トイレの反応範囲はピクトグラムに合わせています。
- 確認画面から2階のおくすり側EV出入口をドラッグして修正案を保存・書き出せます。
- 目的地選択後、経路設定の上段に「通常」「車椅子（EVのみ）」の2択。その下の出発地・目的地を押して変更できます。現在いる場所を地図上でも指定可能。通常は乗り換えの少なさを優先し、同条件なら距離で比較します。2R→9東Bは2階東EVから直行。ナビ中は手順の区間を拡大し、検索・設備欄を隠します。
- トイレなど8種類の設備を上段に横スクロールで表示し、最寄りへ案内。検索候補にも公式写真を表示。レントゲン・CT・MRIは2Sへ。かな・全角半角・略称・複数語で検索できます。
- 6階東Aから1階アイソトープ・PETは、6階の外来棟EVから直接1階へ降ります。
- 救急外来専用精算機は、地図アイコン・設備タブから選ぶと案内します。最寄り精算機の候補には入りません。
- 確認・通路編集の記録は利用者のブラウザ内に保存されます。原本の確認記録、提供PDF、旧図面画像、バックアップは含めていません。

## 経路画面の操作

「経路」を押すと上段に出発地・目的地と入れ替え、上部に通常・車椅子、右下にナビ開始を表示。歩行マークはGoogle Material Icons directions_walk（Apache 2.0）を利用、ライセンスはvendor/material-icons-LICENSE.txt。診療科の公式サイトは各科ページへ接続します。

## 経路の自動照合

経路計算のたびに独立した探索で、乗車回数が最少の経路の中で登録済み経路のコストが最小になるか照合します。複数の出入口と通行制約も比較。現地での通路の正確性を保証する検査ではありません。最大化・拡大縮小の操作ボタンと「ここを出発地に」は外し、地図は指で操作します。出発地は経路画面の出発地欄から指定します。

## 撮影と現在地

公式写真の未登録78件はphoto-checklist.htmlで確認・CSV保存できます。現在地は施設名や地図タップで指定します。Wi-Fi自動測位は未接続。7号館・ロータリー・立体駐車場は概略配置のみで、屋内ナビへの接続は現地確認待ちです。
