# Maji Map · 公開マップ

外来受付と病棟入口への院内ナビゲーションです。GitHub Pagesでは、このdocsフォルダを公開します。

- 地図右下の「2D」「3D」で切り替え。3Dは経路全体を常に表示し、各階の間隔を自動調整して重なりを防ぎます。動く矢印で進む向きを確認し、病棟名・施設名のクリックで直接設定できます（出発地は青枠、目的地は赤枠）。
- 3Dは1本指で移動、2本指で拡大縮小・回転。各階の拡大もできます。ナビの青い点は手順に沿って動く案内位置で、自動測位ではありません。案内欄を左右スワイプして手順を切り替えます。
- 常設検索欄へ直接入力し、左側（スマホは下側）の写真付き施設カードからナビを開始できます。公式写真は施設へのカーソルでも表示し、押すと拡大できます。
- 確認画面から2階のおくすり側EV出入口をドラッグして修正案を保存・書き出せます。
- 通常は乗り換えの少なさを優先し、同条件なら距離で比較します。
- 6階東Aから1階アイソトープ・PETは、6階の外来棟EVから直接1階へ降ります。
- 救急外来専用精算機は、地図アイコン・設備タブから選ぶと案内します。最寄り精算機の候補には入りません。
- 確認・通路編集の記録は利用者のブラウザ内に保存されます。原本の確認記録、提供PDF、旧図面画像、バックアップは含めていません。

## 出典

[近畿大学病院 フロアマップ・施設案内](https://www.med.kindai.ac.jp/floormap_facility.html)を参考に作成しています。地図画像・ピクトグラムの権利は各権利者に帰属します。病院公式のナビではありません。

3Dの階層表示は[近大病院 院内ナビ](https://mynrminto.github.io/kindai-hospital-navi/)を参考にしています。同サイトのThree.js r128 / OrbitControls（MIT）を利用し、ライセンスをvendor/に同梱しています。
