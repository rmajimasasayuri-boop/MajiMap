# Maji Map｜画面の動き・経路計算・更新記録

## 現在の仕様（2026年10月30日）
このページは、アプリ更新時に画面の動き・経路条件・検証結果を書き出すための記録です。経由地機能は利用者の指示で停止し、以前の要件は保留ページに保存しています。

## 画面の流れ
1. 検索初期画面：現在地、地図上で選択、候補から選択、最寄りの出入口を表示。お気に入りを履歴より上に表示し、各10件まで。履歴の☆から登録できます。
2. 候補：名称で検索、または分類から選択。透析は5L、会計は総合受付、薬局はおくすり受取カウンターが先頭候補。余分な階・受付番号の補足を省き、公式写真・公式設備アイコンを表示します。
3. 地図で施設を押すと写真カードを開きます。公式マップの施設領域を選択範囲に使用し、案内の到着点とは別に扱います。未確定の地図タップはプレビューし、ナビ開始までは既存目的地を書き換えません。
4. 経路設定：出発地と目的地、通常・車椅子の2条件。経由地欄・追加ボタンは表示しません。初回は通常、次回は前回の条件を使います。
5. ナビ：青線と動く案内位置で一手順ずつ表示。青い点は測位した現在地ではありません。施設・地図タップで指定した出発地からの案内です。
6. 別の施設のプレビューを閉じると元の経路設定へ戻ります。目的地カードや経路の×は目的地を取り消して検索初期画面へ。候補一覧の〈は検索初期画面へ。検索欄の×で入力フォーカスを呼び出しません。

## 経路計算
登録済みの共用通路を点と接続線のグラフに変換し、職員専用通路と階段を除外します。通常はEV・エスカレーターを使い、乗車回数が最少の経路を優先し、同じ回数なら距離に相当する登録コストが短い方を選びます。車椅子はEVのみです。別の探索で選択結果を照合します。病棟の複数入口も比較します。3Gは南側2か所の三角矢印まで案内し、内部を通り抜けません。
7〜10階の東西病棟間は3階を経由します。6階の職員専用通路は通りません。6階東Aからアイソトープ・PETは6階の外来棟EVから直接下りる条件を保持しています。
「すべての設備」では種類ごとの最寄りを表示し、利用できない設備と救急外来専用の精算機は自動選択から外します。最寄りの出入口は現在使える出入口だけで比較します。

## 出入口の時間
利用者の確認に基づく日本時間の設定です。通常出入口は8:00〜18:00、17:50から「まもなく閉鎖」、18:00〜翌8:00は「閉鎖中」。閉鎖中の出入口は経路から外し、時間外出入口だけを利用します。画面表示中も時刻の変化を確認します。

## 表示と色
出発地は青、目的地は赤、ナビ開始は緑。お気に入り・履歴・選び方ボタンは同じ白地と濃い文字。色の違いは選択状態・警告など意味がある場合に限定します。階ボタンは10階から1階へ1列固定、スクロールせず、なぞって階を変更できます。全体ボタンも階ボタンと同じ大きさです。写真カードは最下部まで、写真は元の比率を保持。端末の安全領域を使い、以前追加した余分な8pxは戻していません。

## 検証と限界
出入口の07:59/08:00/17:49/17:50/18:00/深夜の境界、閉鎖中の実経路除外、検索語、公式4Aの領域を自動検査。既存944経路・3D座標対応の検査も実施します。スマホ相当の画面でカード・検索・取消・階選択を確認します。実機Safariの指操作と院内の現地確認は含みません。通路の正しさは記録・公式図面・利用者の確認に基づきます。

## 更新時の運用
今後の反映ごとにこのページと公開用の説明ファイルを更新し、今回の変更、以前の指定との整合、検証結果、未確認事項を記録します。矛盾がある場合は利用者へ確認します。Wi-Fi自動測位・360度写真は未接続／未撮影です。

## お気に入りの解除とアイコン
★を押すと「お気に入りから削除しますか？」を表示し、キャンセル・削除を選びます。2026年10月31日の追加要望で検索・×・★の記号は24px、押下領域は44px以上。未登録の★は灰色、登録済みは黄色です。

## 画面遷移の分岐表（2026年10月31日）
操作 → 条件判定 → 次の表示、の順に読みます。プレビューは仮表示で、確定済みの目的地とは別です。

| 操作 | 判断条件 | 処理・次の画面 |
| --- | --- | --- |
| 検索を開く | 入力なし／あり | なし：選び方・お気に入り・履歴。あり：全候補と別名を検索。 |
| 候補を選ぶ | 出発地／目的地を選択中 | 出発地：青い点を更新。目的地：場所カードと経路設定。 |
| 地図の別施設を押す | 既存の目的地あり | 写真付きプレビュー。元の出発地・目的地を保持。 |
| 無名地点を押す | 通路接続可／未確認 | 可：仮表示しナビ開始で確定。未確認：警告し元の経路を保持。 |
| 別施設カードの× | 元の目的地あり | 仮表示を閉じ元の経路設定へ。 |
| 目的地カード・経路の× | 目的地取消 | 目的地と経路を消し検索初期画面へ。 |
| 検索の×／候補の〈 | 取消／一覧から戻る | 検索初期画面へ。×で自動フォーカスしない。 |
| 出発地・目的地欄を押す | 別施設カードが開いている | 別施設を閉じ、選択する側の検索を開く。 |
| ナビ開始 | 出発地未指定／経路あり／なし | 場所指定／手順案内／案内不可。 |
| 手順を進める | 同じ階／EVで階移動 | 青い案内点を動かし、EV上下移動と到着階拡大を表示。 |
| お気に入り★ | 未登録／登録済み | 10件まで登録／削除確認。キャンセルで保持。 |
| 階を押す・なぞる | 選択階変更 | 2D・3Dの階を変更。階ボタンはスクロールしない。 |

## 経路計算の分岐表
| 判定 | 条件 | 処理 |
| --- | --- | --- |
| 移動条件 | 通常／車椅子 | EV・エスカレーター／EVのみ。職員専用通路と階段は除外。 |
| 経路比較 | 乗車回数が異なる／同じ | まず回数が少ない経路。同じなら登録距離コスト。 |
| 複数入口 | 利用可能な入口が複数 | 各入口を比較。施設内部の架空の接続は作らない。 |
| 通常出入口 | 日本時間8:00〜17:49／17:50〜17:59／18:00〜翌7:59 | 利用可／まもなく閉鎖／閉鎖中。閉鎖中は除外し時間外出入口へ。 |
| 近くの設備 | 利用可能か・専用設備か | 種類ごとの最寄り。救急専用精算機は明示選択のみ。 |
| 経由地 | 停止中 | 欄・追加ボタン非表示。以前の要望は保留ページに保存。 |
